# Simpletron CPU SIMPLE language compile (SLC)
The study project about compiler creation for fake CPU named is SIMPLETRON

**SBC** is a compilator for a fictional CPU driven by the **SIMPLE (Simple language for SML)**. This project allows you to create low-level programs using by virtual machine SML.

## 🚀 Key Features
- the filename should be ended with extension *.slp (aka simple language program)
